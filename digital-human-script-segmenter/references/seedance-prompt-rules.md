# Seedance 2.0 数字人口播提示词规则

本页提炼自仓库内的《Doubao Seedance 2.0 系列提示词指南》，供数字人口播场景按需加载。

## 适用结构

提示词按“主体 + 动作 + 场景 + 光影色调 + 镜头 + 风格画质 + 约束”组织。引用素材时明确使用 `<图片N>`、`<视频N>`，主体一旦定义，后续保持同一标签。

## 表演

- 动作写到眼神、嘴角、头部、肩背、手指和呼吸，并说明幅度与速度。
- 优先缓慢、轻柔、连续的小动作，避免狂奔、跳跃、剧烈转身等大动态。
- 写清动作衔接，避免每句话触发一个互不相关的动作。
- 情绪要外化：紧张可表现为呼吸变浅、手指轻收、目光短暂偏移；释然可表现为缓慢呼气、肩膀放松、淡淡微笑。
- 沉重内容保持克制，不把“严肃”自动升级为哭泣或崩溃。
- 用户表达的需求边界要翻译成正向表演目标。例如“不要调侃、不要太高兴”改写为“语气平实清晰，神态沉稳自然”；正式提示词尽量少写否定式表演描述。
- 目光使用“交流式视线自然看向镜头附近”，配合自然眨眼、轻微视线偏移和短暂思考停顿。持续“直视镜头”容易生成死盯提词器的感觉。
- 口播停顿要同时写在台词标点和时间轴里。破折号处可写“短暂停顿约半秒，视线下沉，做一次很浅、很慢的自然吸气，再接后半句”。
- 合并段如果后期要从中间裁切，提示词里必须预留气口；可写成“短暂停顿、视线下沉、浅慢吸气、保持姿势”，不要让两段内容无停顿直读到底。
- 自我身份或个人经历可用克制的自我指涉动作：右手从膝上轻微抬起到胸前下方，动作幅度小，不遮挡脸部。事实数据或沉重内容更适合双手交叠放膝上，只允许手指轻微收紧。

## 镜头与时间

- 一个镜头尽量只使用一种运镜，例如固定机位、缓慢推近或平稳横移。
- 复杂内容可用“镜头1、镜头2”按自然顺序描述，但数字人口播通常以单镜头稳定呈现。
- 模型对 `0–3 秒` 等精确时间支持不稳定，不要把每一秒写成一个独立事件。数字人口播需要控制姿态时，可使用 3–5 个连续的粗粒度时间段覆盖全片，并在静止阶段写清保持的姿势；这是姿态稳定策略，不是逐秒分镜。
- 数字人口播需要锁定空间一致性：人物朝向、椅子朝向、机位角度和背景透视关系必须与参考图片一致。参考图是侧面或半侧面机位时，人物和座椅也要保持同一侧向关系，避免人物转正但背景仍是侧面透视。
- 人物参考、表情参考、景别参考和音频参考要分开写。景别素材只写“画面景别和构图参考”，不要让模型把它当人物脸或表情参考。
- 如果甲方要求主机位和特写机位分别出片，提示词要按镜头层级拆开写；主机位负责完整叙述，特写机位负责情绪、转折和价值收束，不要把两种镜头写成同一条无差别模板。

## 默认约束

保持人物身份、服装、场景、音色和光线连续；口型与台词同步；画面仅包含人物及原有背景，不叠加任何文字内容；视频仅包含人物口播人声，环境安静无杂音。Logo、水印等硬性输出排除项按平台支持的明确约束补充。

## 2.0 vs 2.5 垫图分流（Part1 实测）

- **2.0**：上传即强参考污染；白描/深度/带序号的构图图**默认不进 payload**；景别用文字写死（机位角、胸部以上、头肩占比、左右位置）。分辨率只写 API（常用 480p 通结构）。
- **2.5**：更听「只借构图」；结构通关后可 **720p + 按需垫构图图**；垫图仍应先去掉序号/标尺/水印。
- **两轨共守**：提示词不写分辨率；少否定少重复；口播写肢体；每图一句功能角色；旁白式段落不上传 VO。
