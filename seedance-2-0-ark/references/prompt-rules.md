# Seedance 2.0 提交前速查

完整方法论见知识库 `concepts/Seedance2.0提示词工程`。这里只放**出片时必须守的格式**。

## 任务句式

| 任务 | 正确 | 错误 |
|---|---|---|
| 参考 | 参考图片1的人物外观，生成… | 严格编辑图片1 |
| 编辑 | 严格编辑视频1，将X改为Y | 参考视频1，把X改成Y |
| 延长 | 向后延长视频1，保持主体与运镜 | 参考视频1继续往后演 |
| 组合 | 参考图片1的[外观]，严格编辑视频1，[改什么] | 混用「参考视频1」做编辑 |

编辑/延长加了「参考」会被判成参考任务，原片约束失效。

## 特殊字符

| 类型 | 符号 | 例 |
|---|---|---|
| 音乐 | （） | （背景中播放着轻快钢琴） |
| 音效 | <> | <杯沿轻磕桌面> |
| 台词 | {} | {来一口鲜爽} |
| 字幕 | 【】 | 【第一章】（需要无字幕就写「保持无字幕」） |

## 素材上限（2.0）

- 图 0–9（含 first_frame / last_frame）
- 视频 0–3
- 音频 0–3
- 不支持纯音频、文本+音频
- 时长 4–15 秒
- 比例：21:9 / 16:9 / 4:3 / 1:1 / 3:4 / 9:16
- 分辨率：480p / 720p / 1080p / 4k（4k 仅标准 2.0，限流更狠）
