# Seedance 2.5 提示词把关

把提示词当作“生成任务说明书”审查：先判断任务类型和输入素材，再检查职责映射、事件状态、连续性与平台边界。不要把更长、更专业当作更好；删除重复、冲突和不可执行的要求。

## 工作模式

根据用户动词选择模式：

- **把关、审查、检查、看看问题**：只报告问题、影响和修改方向，不直接重写全文。
- **优化、改写、调优、给可复制版**：先简述关键问题，再输出完整修订版。
- **从零写、生成提示词**：先锁定任务类型、素材清单、成片目标和已知参数，再起草。

用户未提供素材或参数时，不虚构素材编号、人物身份、时长、画幅、对白或技术规格。用 `[待确认]` 标记会改变方案的缺口；仍可对已给文本完成其余审查。

## 审查流程

### 1. 建立任务清单

提取并区分：

1. 任务类型：纯文本生成、多模态参考、编辑、首/首尾帧、延长、一键成片或转场。
2. 素材：每个 `@图片N`、`@视频N`、`@音频N` 的真实用途。
3. 主体：人物、商品、道具、场景及其数量与归属。
4. 事件：初始状态、主要变化、结束时可观察状态。
5. 视觉与镜头：景别、机位、单一主运镜、切镜和风格。
6. 声音：说话人、语言/口音、台词、音乐、音效、环境声、字幕。
7. 页面/API 参数：画幅、时长、分辨率等与提示词正文分开。

缺少决定性信息时列为“待确认”，不要用常识替用户补事实。

### 2. 应用对应规则

完整读取 [references/review-rules.md](references/review-rules.md)，再按任务类型检查。不能仅凭通用视频提示词经验裁决 Seedance 2.5 的锁定参数、素材上限或特殊字符。

优先级如下：

1. 用户/客户明确确认的成片目标和限制；
2. 实际上传素材及其真实内容；
3. 本 Skill 的 Seedance 2.5 规则；
4. 创意偏好和通用摄影经验。

若素材内容不可见，只审查文本映射是否完整，并明确“未做素材内容一致性验证”。

### 3. 识别问题等级

- **阻断**：任务类型或母版不明、素材引用不存在、关键职责互相冲突、时间段重叠/断裂、锁定参数写错、编辑范围可能破坏非目标内容。
- **高风险**：主体未逐一绑定、多人/多道具可能串位、阶段无结束状态、首尾帧职责合并、延长边界或声音连续性缺失。
- **优化项**：重复描述、抽象情绪、冷僻术语无可观察解释、镜头要求过多、冗余否定句。

不要用单一总分掩盖阻断项。需要评分时，分别评价“任务明确度、素材映射、事件可执行性、连续性、镜头与声音、平台合规性”，并给出证据。

### 4. 输出审查结论

默认使用以下紧凑格式：

```markdown
结论：可提交 / 修改后提交 / 暂不建议提交

阻断或高风险问题
1. 原文位置或摘录：……
   影响：……
   修改方向：……

可优化项
- ……

待确认
- ……
```

若用户要求优化，再追加：

```markdown
可复制修订版
<完整提示词>

页面/API 参数
- 画幅：……
- 时长：……
```

正文只写模型需要理解的生成内容；将可在页面或 API 设置的参数单列。不要声称能保证逐帧复刻、绝对准确文字或精确到帧的事件。

## 改写原则

- 使用“主体 + 主要动作/事件 + 场景 + 视觉 + 镜头 + 声音”的最小充分结构。
- 逐份说明参考素材“采用什么”；只有可能误带入时才补“不采用什么”。
- 多主体逐一命名、逐一绑定，按场景调用，不要求所有素材同时出现。
- 长事件按连续阶段组织，每阶段只放一个主要状态变化，并写可见的结束状态。
- 优先写可观察表现，不只写“紧张、电影感、高级感”等抽象词。
- 一个镜头优先一种主运镜；冷僻术语同时翻译成主体、方向、速度和可见结果。
- 提示词与参考视频冲突时，已准确提供动作/运镜/顺序的视频负责裁决，不重复逐动作改写。
- 否定约束主要用于素材职责、编辑范围和容易误带入的内容；一般画面尽量正向描述。

## 交付前自检

确认以下条件均满足后才给“可提交”：

- 每份引用素材都存在且职责唯一、明确；
- 人物、商品、道具数量与归属在各阶段一致；
- 每个主要阶段有初始/承接状态和可观察结束状态；
- 时间段连续、不重叠、不越出总时长；
- 编辑任务有唯一母版、唯一修改范围和保持内容；
- 首尾帧逐张声明且画幅一致；延长任务写清边界画面、运动和声音；
- 抽象情绪和摄影术语已转成可见/可听表现；
- 参数锁定规则没有和任务类型冲突；
- 对字幕、公式、标牌、产品参数或帧级时间点未作生成式绝对保证。
